# StudySpace

**CS3617 – Group A9**

## Project Overview

StudySpace is a lightweight, responsive web-based application designed for Brunel University students to reserve study spaces on campus and equipment in laboratories.

The platform allows students to search for available study rooms across campus buildings, filter rooms based on seating capacity and available facilities, and check room availability through an interactive timetable.

Students can also book study rooms, manage their reservations, and access their personal dashboard.

StudySpace also provides an administration portal where administrators can manage study room information, monitor reservations, and manage campus facilities.

The main goal of StudySpace is to simplify the reservation process, prevent double bookings, and improve the management of study spaces across Brunel University.

## Key Features

### Student Features
- Student registration and login
- Search study rooms by building
- View room availability through a timetable
- Book available study rooms
- View upcoming reservations
- Cancel existing reservations
- Filter rooms by seating capacity
- Filter rooms by available facilities
- Access a personal dashboard
- View booking history
- Manage account information
- View equipment reservations

### Administrator Features
- Add new study rooms
- Manage study room information
- View room and equipment reservations
- Monitor campus facility usage

Administrators should also be able to add new study rooms to the platform.
